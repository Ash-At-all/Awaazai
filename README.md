# AwaazAI

AwaazAI is a text-to-speech platform focused on Hindi, Hinglish, and Indian-language voices.

## Features

- Support for Hindi and Hinglish voices
- Multi-provider TTS architecture
- Modular FastAPI backend
- Next.js frontend
- Voice browsing and conversation studio
